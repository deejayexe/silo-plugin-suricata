# Dependencies

The go.mod and go.sum files pin the dependency versions. Their source files have not been modified.

- Silo Plugin SDK: MIT. https://github.com/Silo-Server/silo-plugin-sdk
- mautrix-go, including goolm: Mozilla Public License 2.0. https://github.com/mautrix/go
- go-sqlite3: MIT; SQLite is public domain. https://github.com/mattn/go-sqlite3
- Transitive dependencies retain the licenses in their pinned modules.

Retrieve dependency sources with `go mod download`. The repository owner supplied the logo; no different license is assigned to it here.
