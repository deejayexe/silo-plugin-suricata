Surimatrix

New library content, delivered to your encrypted Matrix room.

Connection checks

Check your Silo account and primary profile, then send a real library poster or the Surimatrix logo to your Matrix room.

Send latest content

Send the most recently added movie or episode from the selected library. Use this to check delivery or resend a notification. Each click sends a new message; automatic notification history stays unchanged.

Automatic delivery

Configure the connection and notification title in Administration → Plugins → Surimatrix. Enable automatic notifications and schedule New content every minute. New episodes are grouped for five minutes after the last addition, up to thirty minutes.

Use one Silo administrator API key and a dedicated Matrix device. Keep the persistent storage directory across restarts to retain encryption keys and delivery state.
